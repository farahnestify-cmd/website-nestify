# Hero video

Add the home-page film here:

- `hero.mp4` (required): H.264, 1920×1080, 10–20 s seamless loop, no audio, ideally under 8 MB
- `hero.webm` (optional): VP9 version, usually smaller
- `hero-poster.jpg` (optional): first frame, shown while the video loads. Add `poster="assets/video/hero-poster.jpg"` to the `<video>` tag in `index.html`.

Until a file is added, the hero shows a dark gradient background.
